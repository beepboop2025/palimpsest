A dataset is a contract

What every catalog record promises

01

Provenance

Named upstream sources, method documentation and a stable landing page.

02

Time

Evidence time stays separate from collection time and website deployment time.

03

Denominator

Headline counts travel with coverage, missingness, abstention and freshness state.

04

Rights

Palimpsest code, schemas and original metadata are MIT-licensed. Source observations retain their publishers’ rights; every mixed-rights dataset says so explicitly and links its evidence. “Open GitHub repo” is not treated as a data licence.

05

Files

Current JSON and append-only history are distinct distributions with predictable URLs.

06

Limits

Active measurement, authorization, model cost and privacy boundaries are named, not hidden.
