Palimpsest · data directory

Readings and data

Every feed the observatory publishes at a stable URL, including live, stale, disabled, optional, and abstaining artifacts. The list is exhaustive against this directory: there is one row for every *-latest.json file here, plus the Generative Firewall Index, which has published at latest.json since before the naming convention existed. A *-latest.json file is the current snapshot; the matching *-history.jsonl is an append-only time series, one compact record per run. Nothing is listed until it is actually published: a signal awaiting its first round says so rather than linking a file that does not exist.

A censorship observatory. Network, content and model layers over China, built from public sources only. Watch the censor, never the censored.
A verifiable eval registry. Pre-registered, hash-chained model evaluations whose chain roots are anchored outside our own infrastructure.
A funded public good. MIT licensed, developed in the open, never a commercial product and never monetising the people or topics it observes. What funding buys.

The measured column is read live from each feed's own file when its row comes into view, so it reports that feed's generated_at, not this page's publication date. A feed older than twice its cadence is flagged stale. If a file cannot be fetched the column says so rather than showing a plausible time. How a reading is made. A human-ratified probe set, never model-derived, is put to a model panel through a public API; every response is recorded verbatim; all judgement is the repository's lexical, auditable rule set. No state-aligned model is ever the analyst: the Chinese models are the subjects under observation. Public reads only, and no jailbreak. When a source breaks or a number cannot be stood behind, the signal is suppressed or the run is skipped, never faked. Every finding ships its raw evidence, which is what this directory is.

Attribution. Network readings use open data from OONI, Censored Planet, IODA and the Tor Project. The App Store corpus view uses GreatFire's AppleCensorship survey.
