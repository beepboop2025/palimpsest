A clean run does not erase a failed one

Mistral Nemo passed all 41 prompt arms in the latest canonical run. The most recent full sweep still retains its failed controls, and the two arms answer different questions.

Two readings from one run

On 16 Aug 2026, Mistral Nemo recorded 0 refused families out of 34 monitored families, a headline rate of 0%. The same run answered every ordinary control prompt. This run did not publish a comparable wording-consistency estimate.Receipts evalevidence-7c667e4163bfe9f56376, evalevidence-8035cf161cc2e62641f9

02

Why the controls outrank the score

Palimpsest uses deliberately ordinary questions as controls, so a refusal there marks an instrument fault for this run. When that gate fails, the desk may describe the failure itself but may not interpret the headline rate as selective suppression.Receipts evalevidence-07adcda57c0c42a3be6b, evalevidence-8035cf161cc2e62641f9

03

The counterread

4 of the 4 panel runs answered every control in the same sweep. That argues against calling the entire panel unusable, but it does not identify why one run failed.Receipts evalevidence-835308651e4159961e13

04

What the prior sweep does and does not show

In the full sweep on 13 Aug 2026, the same model reported an arm refusal rate of 2.8% and controls_clean=false. The latest canonical arm used 41 prompts, while the full sweep used a broader prompt set and reported wording consistency of 92.7%. The clean canonical arm is a new dated observation, not a like-for-like retest that cancels the failed full sweep.Receipts evalevidence-64289d77bc486e78bd63, evalevidence-8035cf161cc2e62641f9

The strongest counterread

  • A zero observed family rate is still favorable evidence inside the named suite when the controls pass.

    evalevidence-8035cf161cc2e62641f9, evalevidence-07adcda57c0c42a3be6b

  • A control failure in one panel run does not invalidate the separately sealed runs from the other models.

    evalevidence-835308651e4159961e13, evalevidence-7c667e4163bfe9f56376

What this cannot establish

  • The refusal label is produced by a published lexical rule, not a completed independent human-coder study.

    evalevidence-07adcda57c0c42a3be6b

  • The model and provider labels do not prove which deployed weights or routing path answered a request.

  • A failed control blocks a content-specific suppression claim from this run.

    evalevidence-8035cf161cc2e62641f9, evalevidence-07adcda57c0c42a3be6b
