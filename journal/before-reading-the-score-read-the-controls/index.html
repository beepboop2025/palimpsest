Why the controls outrank the score

Palimpsest uses deliberately ordinary questions as controls, so a refusal there marks an instrument fault for this run. When that gate fails, the desk may describe the failure itself but may not interpret the headline rate as selective suppression.Receipts evalevidence-07adcda57c0c42a3be6b, evalevidence-5a98ad74fe1432491d2a

The counterread

4 of the 4 panel runs answered every control in the same sweep. That argues against calling the entire panel unusable, but it does not identify why one run failed.Receipts evalevidence-835308651e4159961e13

What the prior sweep does and does not show

In the full sweep on 15 Aug 2026, the same model reported an arm refusal rate of 0% and controls_clean=true. The latest canonical arm used 41 prompts, while the full sweep used a broader prompt set and reported wording consistency of 100%. The clean canonical arm is a new dated observation, not a like-for-like retest that cancels the failed full sweep.Receipts evalevidence-116b3fe899847e30b6f3, evalevidence-5a98ad74fe1432491d2a

  • A zero observed family rate is still favorable evidence inside the named suite when the controls pass.

  • A control failure in one panel run does not invalidate the separately sealed runs from the other models.
