Palimpsest · data directory

Readings & Data

Every dataset the observatory publishes, at stable URLs — grouped below by the layer of the apparatus it observes. Each reading ships its raw evidence beside the headline number, so any figure on this site can be audited from the files below. A *-latest.json file is the current snapshot; the matching *-history.jsonl is an append-only time series, one compact record per run. Nothing is listed here until it is actually published: a signal awaiting its first round says so rather than linking a file that does not exist. Schemas, honest scope, and citation guidance: for researchers.

How a reading is made. A human-ratified probe set (never model-derived) is put to a model panel through a public API; every response is recorded verbatim; all judgement is the repo's lexical, auditable rule set — no state-aligned model is ever the analyst; the Chinese models are the subjects under observation. Public reads only; no jailbreak. When a source breaks or a number cannot be stood behind, the signal is suppressed or the run is skipped — never faked. Machine-readable summary for AI agents: llms.txt. Complete file tree including newer dated readings: github.com/beepboop2025/palimpsest/readings. All data is free to reuse with attribution (MIT).
