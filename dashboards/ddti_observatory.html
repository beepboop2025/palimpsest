⚑ Board memory · every flag, every committed run event-flags-history.jsonl
One row per signal, one column per committed change of the board's flag state — a quiet week adds no columns, so this is the board's event memory, not a clock. The July alarm — the only one this board has ever raised, dated six days before CDT's public documentation — is a red ▲ in the GFW row, where it will stay.

Every flag state is committed to the raw history file; this strip draws from it when the page loads.

◫ Forecast calibration · scored against what happened forecast-ledger-history.jsonl
The board publishes forecast intervals, then scores itself when the readings arrive. Coverage near the target means the intervals are honest; a signal under the climatology baseline is named rather than hidden.

Every scored forecast is committed to the raw history file; this panel draws from it when the page loads.

Provenance · how this score was derived
Method: threat = attention × (1 + 1.5 · novelty). Scope: censor-attention allocation (numerator-only; not a true deletion rate). Source: China Digital Times curated deletion stream.
Safety: public content only · never deanonymises posters or contributors · deletion confirmed by multiple independent checks · signal suppressed when the network is unreliable.
