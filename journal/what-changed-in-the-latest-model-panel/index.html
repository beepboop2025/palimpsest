What changed in the latest transition

The latest panel recorded 0 new refusal transitions and 0 newly answered transitions across 164 paired family comparisons. Those transitions occurred in 0 of 4 named endpoint runs.Receipts evalevidence-4b8b431fe70738a7dc9c, evalevidence-b7b5ae6301c7677fe794

02

One transition is not a trend

The comparison is adjacent and endpoint-specific, so a changed label establishes neither a persistent trajectory nor a common cause across providers. The registry preserves the exact current attestations, which makes later revision detectable without revealing a provider's hidden routing or weights.Receipts evalevidence-4b8b431fe70738a7dc9c, evalevidence-7ea79deb615105a5e78e, evalevidence-b7b5ae6301c7677fe794

03

The churn alarm watches a different failure mode

The anytime-valid monitor is designed to detect repeated instability after calibration, while the adjacent comparison records individual answer-state changes immediately. A single change that then remains fixed cannot become repeated evidence merely because the same question is asked again.Receipts evalevidence-6052bccd5567cb80f11c, evalevidence-7ea79deb615105a5e78e

The strongest counterread

  • No observed transition is favorable evidence of short-run stability inside this exact panel.

    evalevidence-b7b5ae6301c7677fe794

  • An observed transition can reflect endpoint routing, sampling, classifier error, or model change; the eval alone does not select among those explanations.

    evalevidence-b7b5ae6301c7677fe794, evalevidence-7ea79deb615105a5e78e

What this cannot establish

  • Only prompt families present in both compatible adjacent runs enter the paired denominator.

    evalevidence-b7b5ae6301c7677fe794, evalevidence-7ea79deb615105a5e78e

  • Endpoint names do not independently prove that the provider served unchanged weights or routing across runs.

    evalevidence-4b8b431fe70738a7dc9c

  • The lexical answer-state classifier still requires independent human validation for a broader construct claim.

    evalevidence-7ea79deb615105a5e78e
