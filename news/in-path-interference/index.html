Middlebox signatures register at 1.29% in the current OONI window

The decomposition separates interference signatures from transport failure and tests that could not execute.

By Palimpsest Observatory14 Aug 2026 · 19:25 UTCAutomated evidence brief

1.29%middlebox index · across 9,711 completed middlebox tests

What the record says

Finding. The current measurement-weighted middlebox index is 1.29%.

This report is scoped to in-path-interference. It does not merge unlike instruments or infer a cause from co-movement.

How it was measured

rates are computed over COMPLETED tests only (measurement_count - failure_count). OONI's anomaly counter ranges only over completed runs, so a test that never completes has no anomaly rate — it has an execution-failure rate, reported separately

What this cannot establish

  • The index is a weighted aggregate over reporting tests; transport failure and execution blackout remain separate categories.
